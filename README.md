# docs-site

The documentation for the demo organisation's projects, written in Markdown and
laid out for [MkDocs](https://www.mkdocs.org).

This repository belongs to the public demo of
[Zoomies](https://zoomies.sh), a self-hosted GitHub Actions runner fleet. It
exists to give the demo fleet something to check out and build. The workflows in
`.github/workflows/` run on a schedule on a Zoomies runner.

```sh
pip install mkdocs
mkdocs serve
```
